〇、总体结论
技术可行，建议有条件立项。
• 市面已有同类产品（如零刻），技术可行性已被验证；本报告只评估“怎么做、做到哪、花多少、多
久”。
• 样品目标：V2 Windows 半便携运行盘——盘内自带运行时，插入 Windows 电脑脚本直启，数
据全留盘上。V3 双端即插即用首阶段不承诺。
• 周期：约 5～6 周出样品（评估 1 周 + 开发 4 周，保守 5 周）。
• 成本：样品期总成本约 1.1～1.6 万元（硬件 ≤800 元 + 算力 ≤500 元 + 人工约 1.0～1.4 万元）；
量产后单盘边际成本约 135～270 元。
• 降级预案：第 3 周末干净机 PoC 未通过则切换 V1 安装盘，周期与预算不变（见 4.4）。
• 样品验收通过后，与王院长议商业模式（定价、渠道、量产规模）。

二、功能开发到什么程度
2.1 产品分期
版本 形态 本阶段态度
V1 便携安装盘 盘内为安装包 + 模板 + 手册，用户本机 降级预案
安装一次
V2 Windows 半便携运行盘 盘内自带 Node 运行时与 OpenClaw，插 样品目标
Windows 脚本直启，数据全留盘上
V3 Windows + macOS 即插即用 双端多架构产品化 不承诺，二期再议
2.2 用户拿到手的第一体验
→ → → ≤
插盘 双击启动器 填 API Key 开始对话（ 3 步）
不用装任何软件、不需要管理员权限；配置、会话、记忆和文件都存在盘里，换台电脑插盘接着用。
2.3 预装哪些能力
首页四张任务卡 + 一个自由输入框：写东西、读文件、查资料、整理文件夹；背后是一个主 Agent，
共用同一套记忆。
2.4 初始化与配置做到什么程度
工厂侧完成人格与能力边界的预置封装（BOOTSTRAP → SOUL → TOOLS 提前配置好）；用户侧仅
剩一步——首次启动填自己的 API Key。不附带任何 API Key。
2.5 功能清单与完成度标准（验收硬标准）
1. 干净 Win10 / Win11（无 Node/Git/Docker）插盘可启动，启动时间 2 分钟以内
2. 盘符变化仍可正常启动；三台电脑换着插数据不丢，断电拔盘后可恢复
3. 配置、会话、记忆全部写入盘上，盘外文件默认碰不到
4. 首次启动引导自填 API Key，可接入 GPT / Claude / DeepSeek
5. 四张任务卡功能可用；一键恢复出厂预置（清用户数据、保留预置配置）
6. 22 项基本功能全过；联网研究、备份迁移、更新回滚三项至少做成两项
