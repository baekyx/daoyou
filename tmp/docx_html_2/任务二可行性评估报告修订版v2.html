〇、总体结论

结论 技术可行，建议有条件立项。样品目标为 Windows 半便携运行盘；本阶段采用云端大模型 API，不在 SSD 内预置或运行大模型。



  • SSD 中预置：OpenClaw、便携式 Node 运行时、启动/恢复脚本、人格与工具配置模板，以及配置、会话、记忆、日志和用户文件目录。

  • SSD 中不预置：GPT、Claude、DeepSeek 等大模型权重，也不附带任何第三方 API Key。首次启动由用户填入自己的 Key，并联网调用所选模型服务。

  • “数据留在盘上”的准确含义是本地持久化副本默认写入 SSD；为完成推理，用户输入及任务所需的文件片段会发送给所选云端模型服务商，不能宣传为“完全不上云、不外流”。

  • 周期约 5～6 周；样品期总成本约 1.1～1.6 万元；第 3 周末干净机 PoC 不通过则降级为 V1 安装盘。

2.2 用户拿到手的第一体验

标准流程 插盘 → 双击启动器 → 填 API Key 并确认数据提示 → 联网开始使用（4 步）。



目标是不安装 Node、Git、Docker，不要求管理员权限。配置、会话、记忆和用户文件的本地副本保存在盘内，换电脑后可继续使用；云端模型调用需要网络。

2.3 预装能力

首页四张任务卡和一个自由输入框：写东西、读文件、查资料、整理文件夹；背后为一个主 Agent，共用同一套记忆。任务卡仅封装流程，不代表模型已存放在 SSD。

2.4 初始化与配置

工厂侧预置人格与能力边界（BOOTSTRAP → SOUL → TOOLS 等配置）；用户侧首次启动选择模型服务商、填入自己的 API Key，并确认：哪些内容会发送给服务商、哪些内容留在 SSD。产品不附带任何 API Key。

2.5 功能清单与验收硬标准

  1. 干净 Win10 / Win11（无 Node、Git、Docker）插盘可启动，冷启动目标 2 分钟以内。

  2. 盘符变化仍可启动；三台电脑换插数据不丢；异常断电后可恢复，且不损坏核心配置。

  3. 配置、会话、记忆、日志和用户文件默认写入 SSD；通过系统目录扫描验证盘外无非必要持久化残留。

  4. 首次启动可自填 API Key，可接入至少两类云端模型提供商；断网时明确提示“模型服务不可用”，不作离线推理承诺。

  5. 界面在首次发送前展示数据边界：请求及必要文件片段可能传给模型服务商；本地完整副本仍保存在 SSD。

  6. 四张任务卡可用；一键恢复出厂预置只清用户数据、保留工厂配置，并需二次确认。

  7. 22 项基本功能全过；联网研究、备份迁移、更新回滚三项至少完成两项。

2.6 明确不做

macOS、Windows ARM、本地大模型、消息通道、定时任务、多 Agent 编排、企业知识库；不以 Docker/WSL2 为前提；不安装 Windows 系统服务；不附带 API Key、客户数据或默认密码。任何变更须经牵头人审批。

2.7 对外宣传口径

推荐表述 “支持指定版本 Windows 环境的便携式 OpenClaw 运行与交付；运行环境与本地持久化数据随盘携带，模型能力由用户选择的云端 API 提供。”



禁止使用：“完全离线”“数据绝不上云”“插上任意电脑就能用”“SSD 内置 GPT/Claude/DeepSeek 大模型”等与当前方案不符的绝对化表述。

隐私口径失真

统一采用本报告口径；首次发送前显著提示数据去向；说明第三方服务条款由用户确认。

便携性不稳定

盘符、权限、杀软或路径长度导致无法启动。

第 3 周前完成干净机 PoC；锁版本；相对路径；三机换插与杀软测试。

API Key 泄露

用户凭据被读取、复制或写入日志。

不预置 Key；禁止明文日志；优先系统凭据库或加密存储；恢复出厂彻底清除。

开源许可 / 商标

复制销售或宣传使用受限制。

由技术负责人核对 OpenClaw 及依赖许可；保留 LICENSE / NOTICE；未经授权不暗示官方合作。

成本与体验漂移

模型费率、接口或版本变化造成不可控体验。

提供商抽象层、版本锁定、更新回滚；对外明确 API 费用由用户承担。



建议立项条件 只有在“云端 API + 本地持久化”的真实口径获批准、干净机 PoC 可在第 3 周完成、许可证与 Key 存储方案通过技术核对后，才进入 V2 样品开发。
