四、重点避坑提醒
1. 拷⻉ data ⽬录前，必须正常关闭 OpenClaw！ 强制拔盘、直接关机容易造成 sqlite 数据
库损坏，Agent 丢失；
2. exFAT ⽂件系统对 sqlite 性能⼀般，不要同时多台设备共⽤⼀块硬盘读写；
3. 如果后续更新 Agent：需要在⺟盘更新，重新保存 data 模板，再批量刷新所有硬盘；
4. 前端修改⽂件，后续升级 OpenClaw 源码时，注意备份 index.html 等修改过的⻚⾯，避免
覆盖丢失品牌客服代码；
5. 不要把 API 密钥预置在模板内，严格由终端⽤⼾⾃⾏填写。
