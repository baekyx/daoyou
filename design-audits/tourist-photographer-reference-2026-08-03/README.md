# 游客端「全页面 × 操作后状态」视觉审查

审查日期：2026-08-03  
目标设备：移动 H5，390 × 844 为主验收，320 × 720 为窄屏复验。  
视觉基线：`reference/01-photographer-my.png`，并结合游客房间页现有人物抠图和浅绿色品牌氛围。  
约束：未修改路由、跳转目标、业务事件或数据接口；只调整页面结构表现、样式与异常显示。

## 统一体系

- 字体：页面标题 30px、区块标题 18–20px、卡片标题 16px、正文 14px、辅助信息 12–13px。
- 间距：页面横向 18–20px，卡片间距 12–14px；320px 仅缩窄间距与图片，不改变信息层级。
- 卡片：18–20px 圆角、浅描边、弱阴影；同一状态切换保持相同骨架。
- 触控：主要按钮、列表入口、切换控件不低于 44px。
- 滚动：有底栏页面采用“正文单一滚动容器 + 底栏独立占位”，长内容页自身滚动。
- 空状态：图标、标题、说明、行动四级关系一致，不用大面积空白代替状态说明。
