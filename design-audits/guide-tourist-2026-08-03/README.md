# 导游端 × 游客端移动 H5 全链路视觉审查

审查基准：390×844 与 320×693；正式业务组件经 QA 壳直接渲染。截图编号 01–34 为 390px 基础页面，35–46 为 320px 关键页面，47–53 为操作后状态。

## 锁定保留

- 导游首页顶部完整组件：欢迎语、主标题、说明、右侧导游人物抠图、三项绿色数据面板。
- 保留数据含义与排列：在线成员 / 历史房间 / 累计创建。
- 仅允许处理移动端比例、换行、间距、溢出与前后景关系；不替换组件、不删除人物、不改变业务入口。
- 路由、跳转、按钮行为、房间状态判断、字幕/纪要链路均不属于本轮视觉修改范围。

## 系统问题

1. **页面骨架不统一**：部分页面由整页滚动，部分依赖 sticky 底栏，部分内容与底栏处于同一 flex 层；长列表和“我的”页底部操作存在被底栏截断风险。
2. **字号层级偏小且漂移**：多个业务页仍使用 9–12px 承担正文、按钮或状态信息；同级标题在首页、记录、设置和房间内页面中尺寸不一致。
3. **320px 采用压缩而非重排**：导游首页当前房间标题换行、讲解控制台标题省略、工具区与字幕区垂直空间不足。
4. **空状态纵向关系失衡**：游客相册、游客列表、字幕记录等空状态在长屏产生大面积无意义留白；短屏又靠近底栏。
5. **详情与长内容缺少稳定收尾**：会议纪要、帮助反馈、资料设置等页面底部按钮在 844px 内容易贴边或被裁切，缺少统一 safe-area 结束间距。
6. **组件密度不一致**：记录卡片、房间卡片、讲解控制台与设置列表的圆角、内边距、图标容器和按钮高度没有形成同一节奏。
7. **状态切换会改变视觉重量**：筛选、展开、弹窗、密码显示后，局部高度变化缺少稳定的前后间距，容易造成页面跳动和遮挡。

## 统一修复方向

- 建立“固定导航 + 单一正文滚动容器”的移动 H5 骨架。
- 字体级别统一为：30 / 20 / 16 / 14 / 12px；12px 只用于辅助信息，不承担主要操作。
- 统一 20px 页面边距、16px 卡片内边距、12–16px 组间距、44px 最小触控高度。
- 320px 只做网格/横向关系重排，不缩小正文字号。
- 空状态使用剩余空间居中并设置上下限；长列表统一预留底栏与 safe area。
- 弹层与确认框保持在可视区内，正文可滚动，操作区固定在弹层底部。
