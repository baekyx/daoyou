# 需求文档

## 1. 应用概述

**应用名称**：拾光旅伴

**应用描述**：拾光旅伴是一个旅游导览H5网页应用，支持导游创建讲解房间并进行实时讲解，游客加入房间收听双语字幕讲解并互动提问，摄影师为授权房间上传照片。应用基于Vite + React + TypeScript + Tailwind CSS + shadcn/ui构建，使用Supabase提供后端数据存储、实时通信与文件存储能力。

## 2. 用户与使用场景

**目标用户**：
- 导游：创建讲解房间，进行中文原声讲解，推送景区卡片，与游客互动
- 游客：加入讲解房间，实时收听双语字幕讲解，查看景区卡片和相册，提问互动
- 摄影师：为授权房间上传照片

**核心使用场景**：
- 导游创建讲解房间，邀请游客加入，进行实时讲解并推送景区卡片
- 游客通过房间列表、邀请链接或扫码加入房间，收听讲解并提问
- 摄影师为指定房间上传照片，游客可查看电子相册

### 3.2 整体布局结构

**手机端 H5 主容器**（宽度最大 390px，高度 844px）：
- 手机屏幕内容：各页面 UI 内容
- 响应式处理：在桌面端居中显示为手机框架，在移动端自动撑满

### 3.3 公共页面功能说明

#### 3.3.1 首页登录（login）
- 展示应用品牌信息
- 提供微信一键登录按钮
- 展示服务协议与隐私政策链接
- 点击登录按钮触发微信授权登录流程
- 登录成功后跳转至身份选择页面

#### 3.3.2 身份选择（role）
- 展示三种身份选项：导游、游客、摄影师
- 点击任一身份跳转至资料完善页面
- 记录用户选择的身份

#### 3.3.3 资料完善（profile）
- 上传头像（存储至Supabase Storage）
- 填写昵称
- 填写手机号
- 显示当前选择的身份
- 勾选同意服务协议与隐私政策
- 提交后创建用户记录，跳转至对应身份首页

### 3.4 导游角色功能说明

#### 3.4.1 导游首页（guide-home）
- 展示统计数据：在线游客数、累计讲解时长、已讲解景点数
- 展示当前讲解房（若存在），点击进入导游讲解控制台
- 展示历史讲解房列表，点击查看历史记录
- 提供创建讲解房按钮，点击跳转至创建讲解房页面

#### 3.4.2 导游讲解控制台（guide-live）
- 展示当前房间信息：房间名称、在线游客数
- 展示游客列表
- 展示实时字幕记录
- 展示游客提问列表
- 提供景点卡片推送入口，点击跳转至景区卡片库
- 提供分享房间按钮，生成邀请链接与二维码
- 提供结束讲解按钮，点击弹出结束讲解确认弹窗
- 展示双语互动评论流

#### 3.4.3 创建讲解房（create-room）
- 上传房间封面（存储至Supabase Storage）
- 填写房间名称
- 系统自动生成六位数字密码
- 展示导游信息
- 填写预计讲解时间
- 展示隐私说明
- 点击创建按钮，创建房间记录，跳转至房间创建成功页面

#### 3.4.4 房间创建成功（room-success）
- 展示房间号
- 展示六位数字密码
- 展示房间二维码
- 提供分享邀请链接按钮
- 提供复制房间号按钮
- 提供进入控制台按钮，点击跳转至导游讲解控制台

#### 3.4.5 结束讲解确认（end-confirm）
- 展示当前讲解信息
- 展示讲解进度
- 提供确认结束按钮，点击后更新房间状态为已结束，返回导游首页
- 提供继续讲解按钮，点击后关闭弹窗

### 3.5 游客角色功能说明

#### 3.5.1 游客房间列表（room-list）
- 提供查找房间输入框，支持按房间号搜索
- 展示当前可加入的讲解房间列表
- 显示房间封面、名称、景区信息、导游信息、在线人数
- 点击房间跳转至密码验证页面

#### 3.5.2 邀请链接落地（invite）
- 展示目标房间信息：封面、名称、导游信息

- 提供暂不加入按钮，点击返回房间列表

#### 3.5.3 密码验证（password）
- 提供六位数字密码输入框
- 提供向导游询密码按钮
- 提供进入房间按钮，验证密码后跳转至游客实时收听页面

#### 3.5.4 游客实时收听（listening）
- 展示导游信息
- 展示语音波形动画
- 展示双语字幕（中文+英文）
- 提供提问按钮，点击跳转至发送问题页面

- 提供查看房间相册入口，点击跳转至房间电子相册页面

#### 3.5.5 发送问题（question）

#### 3.5.6 字幕与翻译设置（subtitle-settings）

- 设置翻译方向
- 保存后返回游客实时收听页面

#### 3.5.7 景区卡片强提醒（card-alert）
- 展示导游推送的景区卡片通知
- 提供查看详情按钮，点击跳转至双语景区详情页面
- 提供稍后查看按钮，关闭弹窗

#### 3.5.8 景区卡片库（card-library）
- 提供分类筛选功能
- 展示景区卡片列表，支持预览

- 点击卡片跳转至双语景区详情页面

#### 3.5.9 双语景区详情（card-detail）

#### 3.5.10 字幕历史（subtitle-history）

## 4. 功能模块与业务规则

### 4.1 用户与认证模块

**功能**：
- 微信授权登录
- 角色选择（导游/游客/摄影师）
- 资料完善（头像、昵称、手机号）
- 用户协议与隐私政策确认
- 角色切换

**业务规则**：
- 用户首次登录必须选择身份并完善资料
- 头像上传至Supabase Storage，生成公开访问URL
- 用户可在个人中心切换角色
- 同一用户可拥有多个角色身份

### 4.2 讲解房系统模块

**功能**：
- 导游创建房间（自动生成房间号与六位密码）
- 房间列表展示
- 游客通过房间号/邀请链接/扫码加入
- 密码验证
- 房间状态管理（待开始/讲解中/已结束）
- 在线人数统计
- 讲解时长记录

**业务规则**：
- 房间号为系统自动生成的唯一标识
- 六位数字密码由系统随机生成
- 房间创建时状态为待开始
- 导游进入控制台后状态变更为讲解中
- 导游结束讲解后状态变更为已结束
- 在线人数通过Supabase Realtime实时统计
- 讲解时长从导游进入控制台开始计时

### 4.3 实时讲解模块

**功能**：
- 导游开始/暂停/结束讲解
- 游客实时收听（语音流/字幕流）
- 双语字幕显示
- 翻译开关与方向
- 字幕字号调节
- 讲解记录存储与回放

**业务规则**：
- 讲解状态通过Supabase Realtime广播至所有在线游客
- 字幕内容实时广播，游客端根据设置显示中文/英文/双语
- 字幕记录存储至数据库，支持历史回放
- 字幕设置仅影响当前游客

### 4.4 互动与景区卡片模块

**功能**：
- 游客提问（文字）
- 导游查看问题
- 景区卡片库（导游创建/编辑/分类/预览/推送）
- 游客接收卡片强提醒
- 双语卡片详情

**业务规则**：
- 游客提问通过Supabase Realtime广播至导游控制台
- 导游可创建景区卡片，包含中英双语介绍、标签、图片
- 导游推送卡片时，所有在线游客接收强提醒通知
- 卡片推送记录存储至数据库

### 4.5 电子相册模块

**功能**：
- 摄影师为授权房间上传照片
- 上传进度与状态
- 照片管理
- 游客按日期查看相册
- 照片详情（保存/分享/收藏）

**业务规则**：
- 摄影师仅能为已授权房间上传照片
- 照片上传至Supabase Storage，生成公开访问URL
- 照片记录关联房间ID与摄影师ID
- 游客可按日期筛选查看房间相册
- 照片收藏记录存储至数据库

### 4.6 历史与记录模块

**功能**：
- 历史讲解房
- 已完成拍摄任务
- 字幕历史
- 收藏记录

**业务规则**：
- 历史讲解房按结束时间倒序展示
- 已完成拍摄任务按完成时间倒序展示
- 字幕历史支持搜索与字号调节
- 收藏记录按收藏时间倒序展示

## 5. 数据模型

### 5.1 用户表（users）
- id：用户唯一标识
- wechat_openid：微信OpenID
- avatar_url：头像URL
- nickname：昵称
- phone：手机号
- roles：角色列表（导游/游客/摄影师）
- created_at：创建时间
- updated_at：更新时间

### 5.2 房间表（rooms）
- id：房间唯一标识
- room_number：房间号
- password：六位数字密码
- name：房间名称
- cover_url：封面URL
- guide_id：导游ID
- status：房间状态（待开始/讲解中/已结束）
- estimated_duration：预计讲解时长
- actual_duration：实际讲解时长
- online_count：在线人数
- created_at：创建时间
- started_at：开始时间
- ended_at：结束时间

### 5.3 房间成员表（room_members）
- id：记录唯一标识
- room_id：房间ID
- user_id：用户ID
- role：角色（导游/游客/摄影师）
- joined_at：加入时间
- left_at：离开时间

### 5.4 字幕记录表（subtitles）
- id：记录唯一标识
- room_id：房间ID
- content_cn：中文内容
- content_en：英文内容
- created_at：创建时间

### 5.5 提问记录表（questions）
- id：记录唯一标识
- room_id：房间ID
- user_id：用户ID
- content：问题内容
- created_at：创建时间

### 5.6 景区卡片表（cards）
- id：卡片唯一标识
- title_cn：中文标题
- title_en：英文标题
- content_cn：中文内容
- content_en：英文内容
- tags：标签列表
- images：图片URL列表
- category：分类
- created_by：创建者ID
- created_at：创建时间

### 5.7 卡片推送记录表（card_pushes）
- id：记录唯一标识
- room_id：房间ID
- card_id：卡片ID
- pushed_by：推送者ID
- pushed_at：推送时间

### 5.8 照片表（photos）
- id：照片唯一标识
- room_id：房间ID
- photographer_id：摄影师ID
- url：照片URL
- taken_at：拍摄时间
- uploaded_at：上传时间

### 5.9 收藏记录表（favorites）
- id：记录唯一标识
- user_id：用户ID
- target_type：收藏对象类型（字幕/照片）
- target_id：收藏对象ID
- created_at：收藏时间

## 6. 接口与实时通道

### 6.1 Supabase Realtime通道

**房间状态通道**（room:{room_id}:status）：
- 广播房间状态变更（待开始/讲解中/已结束）
- 广播在线人数变化

**字幕通道**（room:{room_id}:subtitle）：
- 广播实时字幕内容（中文+英文）

**提问通道**（room:{room_id}:question）：
- 广播游客提问内容

**卡片推送通道**（room:{room_id}:card）：
- 广播景区卡片推送通知

### 6.2 Supabase Storage桶

**avatars**：存储用户头像
**room-covers**：存储房间封面
**photos**：存储摄影师上传的照片
**card-images**：存储景区卡片图片

## 7. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 微信登录授权失败 | 提示授权失败，允许重新登录 |
| 密码验证失败 | 提示密码错误，允许重新输入 |
| 房间不存在 | 提示房间不存在，返回房间列表 |
| 房间已结束 | 提示房间已结束，禁止加入 |
| 照片上传失败 | 提示上传失败，允许重新上传 |
| 网络断开 | 提示网络异常，尝试重新连接 |
| 实时通道连接失败 | 提示连接失败，尝试重新连接 |

## 8. 验收标准

1. 用户打开应用，进入首页登录页面，点击微信一键登录按钮完成授权
2. 跳转至身份选择页面，选择「游客」身份
3. 跳转至资料完善页面，上传头像、填写昵称与手机号、勾选协议后提交
4. 进入游客房间列表页面，点击任一讲解中的房间
5. 跳转至密码验证页面，输入六位数字密码后验证通过
6. 进入游客实时收听页面，实时接收双语字幕讲解内容
7. 点击景区卡片库入口，查看导游推送的景区卡片
8. 点击任一卡片，查看双语景区详情，完成核心浏览流程
