# 任务二 v1：人员、成本、周期与商业模式重新评估

> 评估日期：2026-08-07  
> 适用对象：学生团队课程/创业验证项目  
> 评估口径：优先复用 GitHub 开源项目，只完成 Windows MVP 样品，不按正式商业软件标准投入

## 1. 重新评估结论

原 v1 的人员数量基本可以沿用现有团队名单，但不应把所有人都计算成全职研发。对于当前目标，真正需要持续动手的只有 1 名技术人员，其他成员兼职完成产品整理、测试、文档和协调即可。

建议采用以下口径：

- 开发方式：基于现有 Windows OpenClaw 桌面项目二次改造，不从零开发界面和运行框架。
- MVP 平台：仅支持 Windows 10/11 x64。
- 运行方式：SSD 中放置应用、运行时和用户数据；由宿主电脑执行，SSD 本身不运行 AI。
- 模型方式：用户填写自己的云模型 API Key；不预装大模型，不做本地离线推理。
- 功能边界：启动、首次配置、对话、数据保存到 SSD、恢复出厂设置。
- 暂不实现：macOS、本地模型、自研 UI、自动更新、消息渠道、多 Agent、企业知识库和复杂安全隔离。

在这个范围下，建议结论是：

- 核心执行人员：1 名技术主力。
- 配合人员：1 名产品/测试、1 名文档/协调，均为兼职。
- 开发周期：7-10 个有效工作日，按学生课余时间折算为 2-3 个自然周。
- 样品期现金预算：约 3,000-6,000 元；如果成员不计补贴且使用现有 SSD，实际现金支出可以控制在 500-1,000 元。
- 商业验证：先制作 3-10 套内测样品，不直接进入量产。

## 2. 人员重新定义

### 2.1 最小团队

| 角色 | 人数 | 预计投入 | 主要工作 |
|---|---:|---:|---|
| 技术主力 | 1 | 6-8 人日 | Fork 开源项目、修改存储路径、便携打包、解决启动问题 |
| 产品兼测试 | 1 | 3-4 人日 | 冻结 MVP、编写验收清单、在不同电脑上测试 |
| 文档兼协调 | 1 | 1-2 人日 | 使用说明、演示材料、采购和进度协调 |
| 技术顾问 | 0-1 | 0.5-1 人日 | 遇到 Windows 打包或许可证问题时提供建议 |

合计约 10-15 人日，但这些工作可以交叉承担。最轻量的实际配置是“1 名研发 + 1 名产品测试”，不需要 5-7 人同时开发。

## 3. 成本重新评估

### 3.1 推荐预算

| 成本项 | 估算 | 说明 |
|---|---:|---|
| SSD 样品盘 | 200-500 元 | 购买 1-2 块 128GB/256GB SSD；已有设备时可为 0 |
| 转接线与包装 | 50-150 元 | 优先使用现有线材，样品不定制模具 |
| 模型 API 测试费 | 50-200 元 | 使用 DeepSeek 等低成本 API 完成测试 |
| 技术人员补贴 | 1,800-3,200 元 | 按 300-400 元/有效开发日、6-8 日估算 |
| 产品测试与文档补贴 | 600-1,200 元 | 按兼职任务包计，不按全月工资计 |
| 预留费用 | 300-800 元 | 备用盘、重新打样、兼容性问题 |
| **合计** | **3,000-6,000 元** | 学生项目建议申请上限 6,000 元 |

### 3.2 两种成本口径

为避免把“项目真实价值”和“学生团队实际现金支出”混在一起，建议同时保留两套数字：

1. **现金支出口径：** 如果学生成员不领取研发补贴，并使用已有 SSD，预计 500-1,000 元即可完成样品。
2. **项目核算口径：** 将学生投入按任务补贴折算后，完整预算约 3,000-6,000 元。

原 v1 的 1.1-1.6 万元并非完全不合理，但它更接近“两名技术人员并行开发四周”的算法。当前改为二次开发后，没有必要保留该投入。

## 4. 周期重新评估

### 4.1 推荐排期

| 阶段 | 有效工作量 | 输出 |
|---|---:|---|
| 范围冻结与仓库跑通 | 1 天 | 开发机运行原项目，确定版本和许可证 |
| SSD 路径改造 | 2-3 天 | 应用配置、OpenClaw 状态、工作区写入 SSD |
| 便携包与默认配置 | 2 天 | 可复制目录、首次启动说明、默认 Agent 模板 |
| 多电脑测试与修复 | 2-3 天 | 至少 2 台 Win10/11 电脑测试通过 |
| 文档、母盘和演示 | 1 天 | 样品盘、使用说明、测试记录 |
| **总计** | **7-10 个工作日** | 可演示 Windows MVP |

学生团队通常无法连续全职开发，因此对外承诺建议写为 2-3 个自然周。第 3 个有效工作日应安排一次 Go/No-Go 检查：只要原项目能运行且状态目录能被重定向，就继续；否则退回“SSD 内安装包 + 一键安装”的展示版本。

### 4.2 对原 v1 阶段的调整

- 删除独立的 macOS 验证周。
- 删除 22 项完整功能验收，改成 8 项 MVP 验收。
- 不等待第 3 周才做干净机验证，应在第 1 周完成。
- 不开发四张自定义任务卡，直接复用现有聊天和配置界面。
- 不安排自动更新、回滚和量产流水线；母盘使用人工复制即可。

## 5. 商业模式重新定义

### 5.1 当前不是正式硬件产品

学生团队第一阶段应把它定义为“可收费的验证样品”，而不是承诺长期维护的消费电子产品。实际销售的是：

> 普通 SSD + 已配置的 OpenClaw 便携环境 + 使用说明 + 基础指导服务。

用户需要自行提供 API Key，并自行承担模型费用。产品宣传不得使用“SSD 自己运行 AI”“完全离线”“所有数据绝不经过云端”等表述。

### 5.2 最简单的试销方式

| 项目 | 建议 |
|---|---|
| 第一批数量 | 3-10 套，不直接量产 |
| 销售对象 | 校内社团、创业活动参与者、熟悉 API 的体验用户 |
| 标准版售价 | 499-699 元/套，具体随 SSD 容量调整 |
| 定制配置服务 | 99-199 元/次，可选 |
| 模型费用 | 用户自备 API Key，团队不代充、不承担持续 Token 成本 |
| 售后范围 | 7 天启动问题协助，不承诺长期免费更新 |

### 5.3 单套成本示意

| 构成 | 估算 |
|---|---:|
| SSD 与线材 | 150-300 元 |
| 包装和说明 | 20-50 元 |
| 复制、检查和交付 | 20-50 元 |
| 售后预留 | 30-50 元 |
| **单套直接成本** | **220-450 元** |

在小批量阶段，499-699 元主要用于覆盖硬件、人工配置和售后，不应预期很高利润。是否建立订阅、企业版或批量销售，应等 3-10 名真实用户完成试用后再决定。

## 6. 最终立项建议

建议以 6,000 元为预算上限、2-3 周为时间上限、1 名技术主力为核心执行 MVP。只要完成“插盘启动、填写 API Key、正常对话、数据回写 SSD、换电脑后仍能读取”五件事，即可判定样品阶段成功。

不建议本阶段继续投入 macOS、离线模型、自研界面或复杂量产方案。
